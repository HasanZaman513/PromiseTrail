PromiseTrail is a local-first Chrome extension designed to help users capture source-linked commitments, set reminders, and keep track of what they owe and what others owe them.

Privacy Policy

Effective date: 1 October 2026

1. Data PromiseTrail handles

PromiseTrail may store information that the user chooses to save, including selected commitment text, whether the commitment is marked “I owe” or “They owe”, client or project name, due date, reminder preference, user-entered notes, source webpage URL and page title, commitment status and timestamps.

2. Where data is stored

PromiseTrail stores commitment data locally in the user's Chrome extension storage on the user's device. PromiseTrail does not operate a backend server or user account system for this data.

3. Data collection and sharing

PromiseTrail does not send saved commitment data to the publisher, does not sell user data, and does not share saved commitment data with third parties.

PromiseTrail does not use advertising trackers, analytics services, AI services or external APIs.

4. Chrome permissions

Storage: Used to save commitments and settings locally in Chrome extension storage.

Context menus: Used to provide the PromiseTrail right-click action that allows a user to capture text they have deliberately selected on a webpage.

Alarms: Used to schedule commitment reminders locally in Chrome.

Notifications: Used to display reminder notifications to the user.

5. Source information

When a user deliberately captures selected text using PromiseTrail, the extension can save the source webpage URL and page title with that commitment. This allows the user to return to the original source later.

PromiseTrail does not monitor or collect the user's general browsing history.

6. Data deletion

Users can delete individual commitments from the PromiseTrail dashboard.

Removing the extension may also remove extension-local data from the user's Chrome profile. Users should export any information they want to retain before uninstalling the extension.

7. Security

PromiseTrail is designed as a local-first extension. Saved commitment data is not transmitted to a PromiseTrail server.

8. Children

PromiseTrail is a general productivity tool and is not specifically directed to children.

9. Changes to this Privacy Policy

If PromiseTrail's data practices materially change, this Privacy Policy will be updated before or alongside the relevant product update.

Support

For questions, support requests, privacy enquiries or issues with PromiseTrail, please contact the publisher using the support or contact information provided on the PromiseTrail Chrome Web Store listing.
